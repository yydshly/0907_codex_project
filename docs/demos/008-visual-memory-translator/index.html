VISUAL MEMORY TRANSLATOR

把一个瞬间，
编辑成一页记忆。

从照片与句子出发，决定什么值得保留，再用版式、色彩和隐喻重新表达。这个项目将视觉创作经验写成了一套 AI 可以遵循的技能。

简单记录 · 暂不深入上游技能 v1.5.0生图效果未实测

原创概念示意 · 非产品截图或模型生成结果

能力载体：创作技能Markdown 规则 + 参数示例 + 参考样张
执行依赖：外部 AI宿主理解规则，图像模型完成生成或编辑
核心资产：设计判断输入分流、审美约束、方向选择与失败修正
01 / CAPABILITIES

它把哪些创作步骤组织起来？

以下为仓库定义的工作方式。具体效果依赖执行规则的模型与图像工具。

01

照片记忆转译

提取姿态、空间结构、主色与情绪，将画面概括成艺术出版页。

保留关键特征，主动省略细节
02

风格试衣间

默认六格探索，可选四格或九格。选号后回到原始照片生成成品。

支持换一组、融合两个方向
03

一句话，一个隐喻

保留用户原句，抽出一个可以画出来的关系，用小型视觉隐喻表达。

纯文本即可开始，默认跳过预览
04

多种视觉载体

水彩、色块、分层贴纸、展览票、纪念纸币、中央邮票与唱片实景。

命名模板可直接进入成品流程
05

可组合的设计参数

分别设定原图展示、版式、风格、抽象度、留白、文字与画幅。

审美规则可拆分，也可组合复用
06

检查与修正

围绕主体、留白、文字和风格检查；画面过满、太写实等问题有修正指引。

清单式指导，尚无自动评分程序
02 / HOW IT WORKS

先理解，再设计，最后生成。

切换输入，查看不同工作路径。这里仅演示规则，不上传素材或调用生图服务。

照片 → 视觉记忆页

示例输入：一张山间徒步照片
01 / 理解读懂这张照片

识别人物姿态、山路动线、空间关系与主题色。

02 / 探索给出六格方向

未指定风格时先预览，改变媒介、版式和抽象度。

03 / 生成从原图做成品

根据选择组织完整指令，交给外部图像模型。

04 / 检查保留关键记忆

检查姿态、留白和画面关系，有问题再修正。

已指定风格或要求跳过预览时，直接进入成品流程。预览单格不作为高清像素源。

“记忆”是一种视觉表达。 当前仓库没有长期记忆库、偏好学习或检索系统。坐标锁定、原图保真与抽象比例都是创作要求，尚无程序保证。

04 / FIT & LIMITS

适合表达感受的地方。

抽象与留白带来风格，也意味着信息被主动省略。应根据交付目标选择。

适合尝试

  • 旅行照片 → 明信片、纪念页与艺术相册素材。
  • 文章观点 → 简洁的视觉隐喻卡。
  • 摄影主题 → 多种艺术语言的系列探索。
  • 设计沟通 → 用候选图帮助用户确定偏好。
  • 文创概念 → 票据、邮票与唱片封面方向。

需要另配方法

  • 准确架构图与数据图：关系与数字应完整保留。
  • 电商主图与完整肖像：与技能默认审美目标不同。
  • 精确文字、原图保真：需要独立排版或程序合成。
  • 可编辑图层：贴纸外观不等于可分层文件。
  • 批量一致性与成本：本次尚未实测。
05 / WHAT WE CAN REUSE

把审美经验，变成可复用能力。

结合我们已有的项目研究，价值主要在于创作流程与规则的组织方式。

从“做得好看一点”，走向
“保留什么、如何布局、怎样验收”。

我们可以借鉴的方法

  • 分别维护输入要求、创作规则与质量标准。
  • 先让用户选方向，再投入成品制作。
  • 将常见失败写成明确的修正动作。
  • 为项目封面与观点配图沉淀视觉规范。

采用前先验证

  • 同一素材对比普通提示词与技能流程。
  • 记录可用率、修改次数与文字准确性。
  • 检查不同图像模型对规则的遵守情况。
  • 统一主文件与参数表中的新增字段。
01 / 固定样本验证

先确认规则是否改善结果，再决定采用哪些部分。

02 / 专属视觉规范

加入我们的配色、版式、正反例与系列模板。

03 / 精确制作流程

通过遮罩、原图合成和文字排版提高可控性。

04 / 偏好与批量能力

增加偏好保存、批量制作、分层输出和自动检查。
