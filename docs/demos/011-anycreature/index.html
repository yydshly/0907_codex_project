HOW IT WORKS

不止把文字展示出来，
而是把描述建造成资产。

01 / 设计

大模型写“施工图”

关节的位置、身体的粗细、角的弯曲、每一步如何摆腿，都写进结构化参数。

02 / 制造

引擎生成真实模型

沿骨架连接截面，生成表面，绑定骨骼，再加入颜色、遮蔽和关键帧动画。

03 / 使用

在项目里观看与互动

导出的 GLB 包含模型与动画。这里用 Three.js 播放，你也可以下载后接入自己的项目。
