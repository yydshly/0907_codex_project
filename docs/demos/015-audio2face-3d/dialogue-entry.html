CONVERSATION / LOCAL SERVICE

人物对话是独立页面。

它有消息列表、输入框和发送按钮。输入内容后，MiniMax 根据上下文生成回复与语音，再由 MuseTalk 生成该人物的口型视频。它与六种动作预览工作台不是同一页面。

在本机打开真实对话

  1. 按实施指引启动 8022 服务和模型工作进程，配置 MiniMax。
  2. 浏览器地址栏输入 127.0.0.1:8022/characters，选择已准备好的人物，点击“使用此人物对话”。
  3. 也可直接输入 127.0.0.1:8022/chat，进入默认人物对话。对话页可以更换人物。
  4. 输入一条消息，点击发送；等待分段回应，可播放、打断或重播。

当前 GitHub Pages 是静态展示站，没有部署对话后端，所以这里不能在线发送消息。六种动作回放也不会生成对话。

两种输入的区别

人物对话：你说“今天好累”，模型组织一段回应，再让人物说出来。

六种动作工作台：你输入人物要说的完整台词，选择表情，生成那句台词的视频；不进行上下文聊天。
