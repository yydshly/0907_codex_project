已经实际运行

Mark v2.3 官方 ONNX 模型；中文音频到面部皮肤动画；平静、喜悦、生气三种指定条件；官方 Maya 角色拓扑的浏览器显示。

当前展示边界

浏览器播放器为本项目编写，使用低秩压缩后的真实模型输出。眼球静态显示；没有接入完整牙齿、舌头和眼球动作，也未复刻全部 SDK 后处理。未测试 v3 扩散模型、自动情绪推断或实时麦克风流。
