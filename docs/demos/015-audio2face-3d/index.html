AUDIO2FACE / TALKING PORTRAIT · 015

让三维人物开口，
也让照片有声音与动作。

3D 路线：音频驱动已适配的三维人物面部，再由渲染器显示口型与表情。
视频路线：照片先生成动作视频，再根据音频重绘口型，合成最终说话视频。

这是独立研究与工程集成项目。照片视频使用 MuseTalk，不是 Audio2Face 的照片生成功能。
