## 产品是什么

Cola 是 MarsWave（火星回响）开发的桌面 AI 助手产品。公开功能涵盖对话、项目工作、记忆、技能管理与定时任务；Cola Skill 是配套的技能发现与分发入口。可用“宿主＋扩展”理解其结构，但 Skill 的形态可能是规则、工作步骤、参考材料或脚本，实际工作仍由模型和工具完成。

我们借鉴的是：用户表达目标，助手结合上下文组织任务、选择技能与工具，提供可检查的过程和结果。这是对公开功能的概念归纳，未核实内部调度算法。

## 如何进入我们的能力库

发现候选 → 按上游仓库和具体技能去重 → 提取能力卡 → 在真实任务中比较效果 → 决定参考、适配使用或沉淀为自有技能。

能力卡保留：解决的问题、触发场景、输入材料、执行步骤、输出结果、依赖条件、适用边界、验收方法，以及来源、版本、许可和实测记录。

已有研究可复用：Skill Zine Summary 已覆盖 photo-revival；ego-lite 已有独立研究；HumanLayer、dzhng 和 jakubkrehel 的技能研究可用于比较方法及增量收益。无需为同一上游重复建立完整研究。
