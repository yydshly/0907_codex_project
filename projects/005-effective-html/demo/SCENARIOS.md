## 设计决策

- 通用报告：编辑式结论区与精确矩阵；指标只使用已有记录可算出的 5/2/0，不作性能排名。
- 海岸专题：#e9e4d7 浅砂、#143f43 深水色、#438899 水位色，标题用本机宋体，正文用系统无衬线。SVG 等高线来自主题；水位仅为视觉示意，不是物理模型或预报。
- 线框：灰阶、系统字、普通边框。三种方案改变上下文密度、分流方式与导航顺序。
- 审核台：三栏分工为稿件、记录、决策；移动端顺序重排。保存模拟延迟 700ms，无真实发布或通知。
- 计划：工作型文档，顺序和依赖有来源；输出字段为对委托的结构整理，不添加实际进度。
- 系统图：节点分工图与事件追踪组合；宽图在移动端容器中滚动，事件列表保持可读，不添加自动动画。

## 实测结果

- 报告筛选“有运行记录”得到 2 项；Effective HTML 依据明确没有无技能基线。
- 专题在桌面与深色手机视口截图检查；键盘把水位滑块推到末端，显示高潮位。
- 线框选择第二条工单显示对应详情；看板与逐件方案可切换，最后一条禁用下一条。
- 原型初始审核与发布禁用；三项勾选后可审核；失败保留检查、重试通过、发布显示边界；取消已核对项撤销审核并禁用发布；退回显示待修改。
- 弹窗 Enter 打开与 Escape 关闭恢复焦点；检查发现浏览器原生反向 Tab 可离开表单，已补充显式首尾焦点循环。
- 计划切换前置筛选显示 3 阶段；R2 来源跳转到原文。
- 图解拒绝路径停止于重新选择文件；重试路径可查看失败和完成；节点可展开职责。
- 六个独立页面均在 390px 浏览器视口检查，文档宽度与 scrollWidth 都是 375px，无外层横向溢出。桌面截图检查六个成果。
- 浏览器仍报告无来源 URL 的 MutationObserver.observe 错误；新增源码未使用此 API，来源未确定。未观察到已测流程受影响。

验证边界：未做完整辅助技术审计、跨浏览器验证、真实后台集成或模型增益基准测试。外部来源链接是资料入口，成果本身无外部脚本、样式、字体或 API 依赖。
