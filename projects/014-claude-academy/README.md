## 内容与价值

提供初学、工作效率、AI 编程、应用开发及教育五条建议学习路线；结合官方 4D 框架帮助理解任务分配、需求描述、结果判断与尽责使用。资源库支持中英文搜索、产品筛选、资源类型筛选和本地完成状态。

标题与简介优先采用官方中文；未匹配的 10 项注明本站译名并链接官方英文资源。路线与练习建议是本站整理，原始课程归 Anthropic 所有，未复制课程正文和测验。

## 后续深入研究

当前完成资源目录和导航整理，后续需要深入研究课程内容及实际应用效果。

1. 基础方法：精读 Claude 101、AI 流畅度框架与基础、AI 能力与局限性，提炼任务描述和结果核验清单。
2. 工作实践：结合真实资料整理任务，研究 Cowork、Skills 与对应教程，记录输入、步骤、产物及适用边界。
3. 开发实践：按需研究 Claude Code、API、MCP 和子代理，用小项目验证工作流程。
4. 案例沉淀：从 148 个使用案例中挑选与当前工作相关的场景，形成可复用模板，并区分官方介绍与实际验证结果。

每次深入研究记录具体资源链接、研究日期、核心方法、实践产物和未解决问题。暂不把目录整理视为课程学习完成，也不预设全部资源都需要逐一研究。
