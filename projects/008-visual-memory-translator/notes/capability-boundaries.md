# 源码依据与能力边界

研究日期：2026-09-07。固定提交：`98a18ef20ba98a124161be7b8caa8e0a7cdaf13b`。以下为静态文档与目录核对，未做生图实测。

所有来源位于 [上游研究版本](https://github.com/TanShilongMario/visual-memory-translator-SKILL/tree/98a18ef20ba98a124161be7b8caa8e0a7cdaf13b)。

| 判断 | 源文件 | 依据与限制 |
| --- | --- | --- |
| 这是规则驱动的创作技能 | `visual-memory-translator/SKILL.md` 与仓库目录 | 主入口定义流程；目录为 Markdown、公开 PNG 样张与许可，无模型权重或图像执行程序 |
| 支持照片、文本、图文分流 | `SKILL.md` 的 Input routing | 照片走记忆转译；纯文本走隐喻；图文保留指定文字 |
| 先探索、再生成 | `references/style-preview.md` | 默认 6 格，支持 4/9 格；最终从原图生成；融合时主风格明确 |
| 组合多个独立设计维度 | `references/parameters.md` | 展示、版式、风格、抽象度等参数为 YAML 示例，不是运行时配置解析器 |
| 文本围绕单一隐喻 | `references/text-visual.md` | 保留原句，提炼一个张力；不做完整情节或图标矩阵 |
| 抽象比例是经验指导 | `references/systems.md` | 定义 high 约保留 15%–30%；未提供度量方法 |
| 局部邮票强调空间不变 | `references/central-stamp.md` | 要求同坐标、同尺度、边界连续；无程序遮罩或坐标约束实现 |
| 质量检查是软性指导 | `references/quality.md` | 清单覆盖原图、留白、文字等；失败表提供追加提示词，没有自动评分 |
| 有节日规则 | `references/holidays.md`、`SKILL.md` | 对话日期窗口 ±1 天，可关闭；不是照片时间识别 |
| 不提供长期记忆系统 | 仓库完整文件树 | 没有数据库、检索、偏好持久化或训练流程；属于基于当前实现的边界判断 |
| 参数文档存在同步欠缺 | `SKILL.md` 对比 `references/parameters.md` | 主文件新增的纸币、中央邮票、唱片及部分输入/节日字段未完整进入参数表 |

## 后续实测建议

准备旅行、人物、建筑、食物、纯文本各一组固定输入，保持图像模型、输出尺寸与重试预算相同，对比普通提示词和技能流程。记录首轮可用结果、选择耗时、重试次数、主体变化、文字错误、系列一致性及实际成本。不同指标单独记录，不在没有数据时宣称提效比例。
